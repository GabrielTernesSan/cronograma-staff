# Arquivo do roteiro anterior

Os arquivos numerados desta pasta preservam os laboratórios do roadmap anterior, focado em .NET/Staff. Eles não são mais a fonte ativa da aplicação e não devem ser interpretados como progresso no novo plano.

Os conhecimentos de .NET que continuam relevantes foram reposicionados nos laboratórios ativos: API e testes no mês 2, filas e idempotência no mês 7, eventos no mês 13 e modernização de legado no mês 16.

A fonte de verdade atual está em `lib/data/blocos.ts` e `lib/data/cronograma.ts`; ela alimenta os 30 laboratórios mensais da interface.
